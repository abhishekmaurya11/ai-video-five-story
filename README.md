Required NPM Packages to Install
Run this command in your terminal:

bash
npm install express multer fluent-ffmpeg ffmpeg-static cors uuid
You also need to have FFmpeg installed on your system:

Windows: Download from https://ffmpeg.org/download.html and add to PATH

Mac: brew install ffmpeg

Linux: sudo apt install ffmpeg

How to Run
Save this code as index.html

Open terminal in the same folder

Run: node index.html (the backend will start on port 3000)

Open browser to http://localhost:3000
